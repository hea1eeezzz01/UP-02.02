# План первого цикла командной разработки (Kanban)

Доска соответствует колонкам из задания на учебную практику: Backlog, To Do, In Progress, Review, Done.

## Распределение ролей

| Роль в команде | Обязанности |
|---|---|
| Тимлид / интегратор | Планирование, декомпозиция, проверка изменений и объединение веток |
| Разработчик | Реализация интерфейса, маршрутов Flask, базы данных и функций тестирования |
| Тестировщик | Проверка регистрации, ролей, таймера, случайного порядка, результатов и PDF |

## Kanban-доска

| Backlog | To Do | In Progress | Review | Done |
|---|---|---|---|---|
| Добавить редактирование тестов | Подготовить структуру проекта | Реализовать базу SQLite | Проверить авторизацию | Подготовить README.md |
| Добавить расширенную аналитику | Создать модели пользователей и ролей | Реализовать таймер и прохождение | Проверить перемешивание вопросов | Создать `.gitignore` |
| Настроить CSRF и HTTPS для публикации | Подготовить страницы входа и регистрации | Реализовать панель преподавателя | Проверить PDF-экспорт | Создать ER и UML-диаграммы |
|  | Добавить демонстрационные тесты | Реализовать журнал нарушений | Проверить права доступа | Реализовать базовый каталог тестов и конструктор тестов |

## Предлагаемые ветки Git

```text
main
├── feature/auth-and-roles
├── feature/quiz-timer
├── feature/randomization
├── feature/anti-cheat
├── feature/teacher-analytics
├── feature/quiz-builder
└── feature/pdf-export
```

Примеры команд для первого цикла:

```bash
git init
git add .
git commit -m "chore: create testing module structure"
git branch feature/quiz-timer
```

После выполнения задачи следует создать коммит с понятным сообщением и передать ветку на проверку тимлиду.
