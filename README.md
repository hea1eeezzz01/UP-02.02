# Модуль тестирования знаний с таймером и сохранением результатов

Учебное веб-приложение по выбранной теме № 6 из задания для группы 4-1П9. Проект разработан на Python, Flask, SQLite, HTML, CSS и JavaScript.

## Функциональные возможности

### Студент
- Регистрация и вход в личный кабинет.
- Просмотр каталога из шести тестов: Python, HTML/CSS, JavaScript, SQL, Git и Flask/HTTP.
- Прохождение теста с обратным отсчётом и автоматическим завершением по времени.
- Случайный порядок вопросов и вариантов ответов. Порядок фиксируется для каждой попытки, поэтому результаты корректно проверяются и после обновления страницы.
- Просмотр баллов, процента правильных ответов и пояснений.
- Просмотр собственной истории результатов.
- Скачивание отчёта о своей попытке в PDF.

### Преподаватель
- Вход в панель преподавателя.
- Создание тестов с названием, описанием и ограничением времени.
- Добавление от 1 до 30 вопросов с четырьмя вариантами ответа и выбором правильного варианта.
- Добавление пояснений к правильным ответам.
- Сохранение теста черновиком, публикация и снятие с публикации.
- Просмотр завершённых попыток всех студентов: ФИО, тест, дата, баллы, процент, статус и количество нарушений.
- Просмотр детального результата каждого студента.
- Анализ сложности вопросов на основе ответов всех студентов.
- Скачивание отчёта о каждой попытке в PDF.

### Контроль процесса тестирования
- Фиксация ухода со страницы, потери фокуса окна и выхода из полноэкранного режима.
- После трёх зафиксированных нарушений попытка автоматически завершается со статусом «Нарушение правил».
- События нарушений сохраняются в базе данных.
- Контекстное меню и копирование/вставка отключаются на странице тестирования.

**Ограничение браузера:** обычное веб-приложение не может физически запретить пользователю переключиться на другую вкладку или использовать системные сочетания клавиш. Поэтому реализованы полноэкранный режим, обнаружение и запись ухода со страницы и автоматическое завершение после установленного количества нарушений. Это контроль и фиксация событий, а не абсолютная защита от списывания.

## Роли и демонстрационные учётные данные

- Студент может самостоятельно зарегистрироваться через страницу «Регистрация».
- Демонстрационный преподаватель создаётся автоматически: **логин `teacher`, пароль `teacher123`**.
- Демонстрационный студент также создаётся автоматически: **логин `student`, пароль `student123`**.
- Преподаватель может создавать тесты, добавлять от 1 до 30 вопросов, задавать четыре варианта ответа, отмечать правильный вариант, добавлять пояснения, устанавливать время и публиковать тест или сохранять его черновиком.
- Опубликованные тесты появляются в каталоге студента. Черновики студентам не показываются. Преподаватель может в любой момент опубликовать тест или снять его с публикации.
- Перед реальным использованием смените демонстрационные пароли. Пароли хранятся в виде хешей.

## Установка и запуск в Windows

1. Установите Python 3.10 или новее.
2. Распакуйте архив и откройте терминал в папке `module_testing_knowledge`.
3. Выполните команды:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python src/app.py
```

4. Откройте `http://127.0.0.1:5000` в браузере.

Для Linux/macOS активируйте окружение командой `source .venv/bin/activate`, затем выполните те же команды `pip install` и `python src/app.py`.

При первом запуске приложение создаёт папку `instance`, базу `knowledge_testing.db`, демонстрационные тесты, аккаунт преподавателя и аккаунт студента. Если база из предыдущей версии уже существует, поле автора теста добавляется автоматически, а демонстрационный аккаунт студента создаётся при следующем запуске.

## Если PDF не скачивается

- В активированном виртуальном окружении установите библиотеку: `python -m pip install reportlab`.
- Перезапустите сайт командой `python src/app.py`.
- Для отображения русских букв в PDF в системе должен быть установлен Arial, DejaVu Sans или Noto Sans.
- Кнопка «Скачать PDF» отдаёт файл `result_Номер.pdf`. При ошибке генерации приложение покажет сообщение на странице результата.

## Запуск автоматических тестов

```powershell
python -m unittest discover -s tests -v
```

## Технологии

- **Python 3.10+** — серверная логика.
- **Flask** — веб-фреймворк и маршрутизация.
- **SQLite** — хранение пользователей, тестов, попыток, ответов и событий контроля.
- **HTML/CSS** — интерфейс.
- **JavaScript** — таймер, индикатор прогресса и события потери фокуса.
- **ReportLab** — формирование PDF-отчётов.

## Примечание

Это учебный прототип для локального запуска. Для публикации в интернете необходимо задать собственный `SECRET_KEY`, включить HTTPS, добавить CSRF-защиту, настроить резервное копирование и заменить демонстрационную учётную запись преподавателя.
